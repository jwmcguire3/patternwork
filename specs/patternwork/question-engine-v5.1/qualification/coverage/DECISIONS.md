# Coverage decisions

## Start from the current gaps, not from the oldest prompts

The prior v7 evidence audit already had useful action/function/sequence evidence. The missing detail was mostly whether an experience was privately permitted, whether noticing it brought choice, whether two protective concerns shared a job, whether a response actually returned, whether support left a need unmet, and what recovery and relational pace felt like. This release adds neutral discriminators for those questions rather than restores fixed-role questionnaires.

## What was added

36 conditional templates plus three routes into existing questions. The original 30 Mapping items, original 64 Deepening items, their option IDs/wording and the M10 observable variant are unchanged. New data have new IDs, a new question release and a new runtime binding. The existing v7 report principles remain; the report binding is updated for the new source and its actual evidence channels.

## What the router does not decide

All new coverage targets terminate as descriptions, alternatives, uncertainty or missingness. None emits `exile_exists`, a Self score, an attachment type, an obligatory part relation or an exact number of findings. The report writer may reason from the new material without being limited to precompiled structural summaries. Its claims must still retain source, scope, alternatives and the distinction between direct report and interpretation.

## Why these alternatives matter

D73/D74 permit ordinary privacy with full internal acknowledgment. D65/D66 separate curiosity and choice from detachment. D76 allows different concerns, one practical wish, or neither pull preventing anything. D78 distinguishes actually returning, only wanting to return, no return, an ended event and unclear recall. D91/D92 allow a sufficiently met need. D98 permits useful support without surrendered autonomy. Those alternatives must close the relevant question successfully, not trigger a search for a concealed problem.

## Timing without false precision

D84 asks for a broad retrospective estimate of first easing and accepts no easing or an unreliable estimate. D85 separately records function/ease order. Neither measures autonomic recovery or exact causal thresholds. D99 is marked as respondent-reported typicality, not a newly sampled occurrence; the current event graph remains the graph of actual identified events.

## Testing changed the implementation

Initial tests found a stale 53-handler assertion in the active copied test, newly added scope questions displacing the established reassurance branch, and a self-conclusion route that could be closed by a different vulnerability question. The handler test now checks all actual base and extension rules; D81/D89/D90 use the lower texture tier; a separate D22 opening rule preserves that distinct evidence job. The historical reference files were not changed to obtain these results.

A further review separated the first move's continuing-to-function effect (D83) from later recovery (D86/D100), made incompatible timing answers exclusive, preserved D89/D90 as remembered expectations and D99 as typicality, and tied new follow-ups to live parent content so corrections remove only their dependents.

## Limits on the word complete

The deliverable completes authored paths for the currently agreed report capabilities. It does not establish psychometric completeness or guarantee that a short route samples every capability. Missing evidence remains missing. New questions, automatic gates and report outcomes still need real-user comprehension testing and live semantic report qualification before production activation.

Final wording review also replaced a near-duplicate D90 desired-response question with a remembered **prediction of the other person’s response**. D43 already captures what the respondent wanted their own follow-up to achieve; D90 must not simply ask for the same motive again.

The final inherited regression suite caught an additional interaction: D22 could close the older combined `self_pressure` target before D15 established the function of criticism. The new release separates those jobs: `self_pressure` resolves through D15; `coverage_self_conclusion` resolves through unchanged D22. A self-belief selection is no longer treated as a replacement for function evidence. The historical 5.0 source remains unchanged.
