# PWQE 5.1 evidence → report interface

The assessment preserves canonical observations, currentness, episode identities,
selected steps, explicit temporal relations, comparisons, target resolutions and
missingness. These records, not target names or a finding count, are the report's
basis. Active PWRP prompts and their independent version binding live in the
package's `reporting/` directory. No v6 writer is activated by this runtime.

New capture kinds are descriptive. Internal permission, awareness/choice, belief
force, perceived common concerns, reported returns, estimated intervals, current
relational expectations, requested-versus-met need, pace, exploration support and
meaning after easing remain available as original observation leaves. They do not
assign exiles, Self scores, attachment classes, vagal states or part identities.

D78.returned explicitly supplies a later return step after the second response.
Its edge preserves a new `return` node rather than cycling backward in event time.
D99 is a reported generalization, never additional independent occurrences.
D84 is a retrospective coarse estimate, never objective physiological latency.

Corrected source leaves invalidate dependent observations and target resolutions.
A released report snapshot is never mutated. The next report request requires the
new source and evidence binding and a fresh semantic review.
